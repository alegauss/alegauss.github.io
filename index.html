Web · Cost model

usage simulator

What a Claude Code task really costs, and how far each plan carries you — with every coefficient measured from real session transcripts instead of assumed.

  • ✓Calibrated, not invented — 79,377 requests across 1,864 tasks set the cache factor, the calls per task and the fan-out shares.
  • ✓The five-hour window — the limit that actually stops your afternoon, not a monthly average that never bites.
  • ✓Says what it does not know — the plan budgets are labelled as estimates, because nothing published states one.
One HTML file · no build No tracking · runs offline Apache 2.0

Docs · CLI · Claude Code plugin

roadkeep

A CLI that owns the writes to your ROADMAP.md, CHANGELOG.md and IMPROVEMENTS.md, so the format is a schema at the point of insertion instead of a convention the author is asked to remember.

  • ✓Refused at the write path — a field with a length limit declines before the prose exists; a linter only reports after the tokens are spent.
  • ✓Round-trip or don't write — parse → render → byte-identical, or it declines to touch your hand-edited file at all.
  • ✓Query instead of read — next-id, deps and origin answer with --json provenance, so a question costs no context.
Python ≥3.11 · zero runtime deps Ships as a Claude Code plugin Early · 8 of 36 tasks shipped

Git · CLI

commitclerk

Better git commit messages in one command. It reads your staged diff, asks an LLM for a Conventional Commits message, shows it to you, and commits.

  • ✓Conventional Commits 1.0.0 — written from the diff, not from your memory.
  • ✓One Python file, zero dependencies — drop it on your PATH and go.
  • ✓Doc-aware — knows a docs-only change isn't a new feature.

Windows · Tray app

Claude Code Tray

Your Claude Code usage, always in the tray. A native Windows monitor that shows your rate-limit percentage as a crisp, DPI-aware icon.

  • ✓Smart projection — burn rate tells you if you'll hit the limit before the reset.
  • ✓24h breakdown — statistics and insights, computed on your own machine.
  • ✓Privacy-first, zero config — reads only the usage data Claude Code already writes locally.

How these are built

Your machine, your data

Nothing is collected or phoned home. What runs locally stays local — the only network call is the one you configure yourself.
